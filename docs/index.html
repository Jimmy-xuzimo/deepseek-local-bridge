能力一览

标准接口 + 网页版能力全覆盖，客户端几乎不用改配置。

OpenAI 兼容

提供 /v1/chat/completions（SSE 流式）、/v1/models 与 /v1/files，任何兼容客户端直接填地址即可。

深度思考

网页版思考过程通过 reasoning_content 回传，Chatbox 里可以直接查看模型的推理链。

联网搜索

一键开启网页版联网搜索，回答里保留网页给出的参考链接。

附件直传

图片、PDF、TXT/MD、DOCX 都能丢给网页版解析，接口层兼容图片与文件两种写法。

工具调用

把 function calling 桥接到网页版，配合 CC Switch 可让 Codex CLI 完成读写代码、跑测试的完整闭环。

多会话映射

客户端每个对话对应一个网页对话；新建会新建，切回旧对话会切回原来的网页对话，上下文不丢。

局域网可用

开启“在网络中提供服务”，手机、平板用 192.168 地址加同一个 API Key 即可接入，CORS 随时开关。

稳定与可控

串行队列、请求取消、网页限流识别（429）、请求最小间隔、页面诊断与选择器覆盖，出问题能自查。

跨平台

Windows / macOS / Linux，x64 与 ARM64 都有构建；一键脚本、便携包与 CI 三件套齐全。

三步开始

不需要官方 API Key，用你已有的网页版账号即可。

  1. 1

    启动并登录一次

    运行 start.bat / ./start.sh，弹出专用浏览器窗口登录 DeepSeek；登录状态长期保留，可以最小化窗口。

  2. 2

    本地服务就绪

    设置页自动打开，显示 127.0.0.1:8317、API Key、思考/联网开关与局域网地址，还带一键自测。

  3. 3

    客户端接入

    Chatbox 填地址与 Key 就能聊；Codex CLI 通过 CC Switch 的路由模式接入，工具调用自动桥接。

客户端接入

复制粘贴即可，配置项一共三个：地址、Key、模型名。

Chatbox · OpenAI API 兼容
API 域名  http://127.0.0.1:8317
API Key   在设置页「客户端接入」一键复制
模型名称  deepseek-web

Chatbox 会自动补 /v1；连不上时改成 http://127.0.0.1:8317/v1 再试。

CC Switch · Routing
API Request URL  http://127.0.0.1:8317/v1
Default Model    deepseek-web
Upstream Format  OpenAI Chat Completions（需要路由）
Routing          打开总开关并启用 Codex，然后重启终端

Codex 用 Responses 协议，交给 CC Switch 转成 Chat Completions 再进本服务。

OpenAI SDK / curl
curl http://127.0.0.1:8317/v1/chat/completions \
  -H "Authorization: Bearer $DSB_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-web","stream":true,
       "messages":[{"role":"user","content":"你好"}]}'

Python 里把 base_url 设为 http://127.0.0.1:8317/v1 即可直接复用 OpenAI SDK。

常见疑问

需要官方 API Key 吗？

不需要。它使用你已登录的 DeepSeek 网页版账号，因此也不受官方 API 计费影响。

数据会上传到别处吗？

服务只监听本机，登录配置、附件、日志、会话映射都存在你的数据目录里；日志只记录长度与耗时，不记录对话内容和凭证。

网页改版了怎么办？

设置页可以一键保存诊断信息（页面结构与选择器命中情况），在数据目录放一个 selectors.json 就能覆盖失效的选择器，不用改代码。

会有账号风险吗？

这是非官方方式，可能受网页改版与账号风控影响，请仅个人学习使用、遵守服务条款，避免高频或商用请求。

Windows 提示“不信任的应用”怎么办？

便携包没有代码签名，首次运行会被 SmartScreen 拦一下：右键 zip → 属性 → 勾选“解除锁定”再解压，或点“更多信息 → 仍要运行”即可；也可对照 Release 里的 SHA256SUMS.txt 校验文件。
