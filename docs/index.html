05 / KNOW THE BOUNDARIES

开始之前，了解边界。

非官方项目，仅限个人学习使用。网页改版、账号风控和服务条款都可能影响可用性；请勿商用或大规模并发。

常见问题与排查 ↗
需要 DeepSeek 官方 API Key 吗？

此项目使用已登录的 DeepSeek 网页账号，不使用官方 API Key。客户端需要填写的是 Bridge 在本机生成的 API Key。它不是官方 API 的替代服务承诺，可用性与使用限制仍受网页服务影响。

“本地”意味着对话不会联网吗？

不是。桥接程序、浏览器配置与会话映射在本机运行和保存，但消息与附件会发往 DeepSeek 网页服务处理。它不是离线推理，也不保证所有数据都不离开设备。

能让手机或局域网里的设备使用吗？

可以通过设置页提供的局域网地址和相同 API Key 接入。当前配置默认开启局域网服务与 CORS；端口及局域网开关变更需重启。管理页仅允许本机访问。请勿将端口映射到公网，也不要关闭 API Key 校验。

工具调用与流式有什么限制？

工具调用通过提示词协议桥接，需要等待完整回答后再解析；格式无效时回退为普通文本。一个账号串行处理请求，多步任务会排队。Codex CLI 使用 Responses 协议，需要经 CC Switch 路由转换。

Windows 提示未知发布者怎么办？

当前 Windows 便携包未做代码签名，可能出现 SmartScreen 信誉提示。先确认下载来源，并对照 Release 中的 SHA256SUMS.txt 检查文件。签名状态、信誉提示与恶意软件检测是不同事项，处理方式详见仓库文档。

网页改版或登录过期了怎么办？

先在本机设置页检查登录状态并重新登录。遇到网页结构变化，可保存诊断信息，根据文档使用 selectors.json 覆盖选择器，并通过 Issues 提供经过脱敏的问题说明。
