登录 DeepSeek

点击下面的按钮会打开一个专用浏览器窗口（不影响你日常使用的浏览器）。登录一次即可长期保留； 浏览器窗口保持运行（可以最小化），服务通过它来收发消息。

2

服务设置

端口与“在网络中提供服务”需要重启服务生效：运行 scripts\restart.ps1（macOS/Linux 用 scripts/restart.sh），或关闭后重新启动。CORS 立即生效。

3

客户端接入

模型名称 deepseek-web
API Key -
  1. 设置 → 模型 → 添加自定义供应商（选择 OpenAI API 兼容）。
  2. API 域名填 http://127.0.0.1:8317（Chatbox 会自动追加 /v1；连不上再试 http://127.0.0.1:8317/v1）。
  3. API Key 粘贴上面的值，模型名填 deepseek-web。
  4. 手机上使用时，把地址换成上面列出的局域网地址（需开启“在网络中提供服务”并重启服务）。
  1. CC Switch → 添加供应商 → 选择 Codex 类型。
  2. API Request URL 填 http://127.0.0.1:8317/v1，Key 填上面的 API Key，Default Model 填 deepseek-web。
  3. Advanced Options → Upstream Format 选择 OpenAI Chat Completions（需要路由）。
  4. 打开 Routing 总开关并启用 Codex，重启 Codex 终端后生效。
